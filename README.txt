PRAVEEN R — PORTFOLIO WEBSITE

FILES
- index.html: website content
- style.css: dark-blue responsive design
- script.js: mobile navigation and current year
- README.txt: these instructions

VIEW ON ANDROID
1. Extract the ZIP file using your phone's Files app.
2. Open index.html in a browser to preview the website. Some file managers may not support this; you can use an HTML editor app.

PUBLISH USING GITHUB PAGES
1. Open your GitHub repository in Chrome.
2. Tap Add file > Upload files.
3. Upload index.html, style.css, script.js, and README.txt from the extracted folder.
4. Ensure index.html is in the repository's main/root folder, not inside another folder.
5. Tap Commit changes.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
8. Wait for deployment and open the published Pages URL.

EDITING
- Replace the project placeholder in the Projects & Achievements section when you have project details.
- Add a LinkedIn or GitHub link when you want to share those profiles.
- The skill bar lengths are decorative, not formal ratings.

This portfolio uses the details supplied in the resume. No project, certificate, or social profile details have been invented.
